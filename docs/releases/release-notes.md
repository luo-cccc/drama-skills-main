# 更新记录

这里按日期记录本仓库面向创作者的更新；上游历史版本与详细升级约定见 [CHANGELOG](../../CHANGELOG.md)。

### 2026-10-30

- 十二个技能覆盖从原著、剧本、台词专项到参考图、分镜、生产和剪辑的完整流程，保留打戏编排、画风投影与面部表演的按需指导。
- 角色参考图可以独立制作；锚点与派生视图分别确认，当前文件或父图失效时显示明确的过期原因。
- 俯视站位支持拖动、姿态、朝向和群演调整，保存回正式分镜；外部修改产生冲突时保留草稿，并可复制调整或显式重新载入。
- 关闭页面、刷新或切换项目时提示未保存站位；保存期间继续编辑也会保留后续调整。
- GPT Image 与 Qwen Image 支持真实图片引用、异步任务恢复；Qwen 同时提供 ComfyUI 路径。
- 剧本逐块来源、跨镜对白容量、资产提示与参考可用性在创作台中可核对，文档齐备与检查通过分别表达。
- Windows 原文编辑定位兼容换行差异，查看问题后可直接打开对应的创作文档。

既有项目请按真实镜头职责补齐完整来源引文；文本声明完整仍需要创作者核对实际动作和表演。
