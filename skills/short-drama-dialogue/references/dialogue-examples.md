# 对白合成示例

只在需要对照完整 Before/After、检查人物声音差异或比较直给与含蓄方案时读取。

情境：姐姐要弟弟交出母亲留下的柜子钥匙。弟弟已答应房东不让她先看原件。两人都知道合同存在。
场景结束时，姐姐必须发现弟弟还没交，并且关系更冷。

## 1. 说明朗读版

```text
姐姐：妈妈把合同放在柜子里，你把钥匙给我。
弟弟：我不能给你，因为我答应了房东。
姐姐：我是你的姐姐，我有权看。
弟弟：我们关系不好，所以我不相信你。
```

问题：双方直接说出作者需要观众知道的信息；每句只补充理由，没有试探、交换或反制。

## 2. 压力修订

```text
姐姐把卷帘门遥控器装进口袋。

姐姐：钥匙。

弟弟：你先把门开了。

姐姐：你要真把原件交出去了，还怕我看柜子？

弟弟捏住钥匙圈，不让铜钥匙垂下来。

弟弟：房东只要一份合同。

姐姐：他要的是哪一份？

弟弟：你连母亲最后签的是哪一页都不知道。

姐姐把手从遥控器上移开。

姐姐：所以你还没交。
```

变化链：

- 姐姐用门交换钥匙；
- 弟弟反设条件；
- 姐姐用“怕看柜子”试探；
- 弟弟为压住她，泄露合同不止一份；
- 姐姐据此改判，撤回原交换条件。

人物没有宣布“我们互不信任”，但关系更冷，信息也前进了。

## 3. 同一事实的声音差异

事实：原件仍在店里。

- 重证据的人：`房东收到的那页没有骑缝章。原件没出这道门。`
- 重承诺的人：`我答应交，不等于已经交。`
- 重体面的人：`我只确认收到文件，不参与分辨你们家的哪一份算原件。`

差异来自三人各自认定什么才算证据、怎样保护自己，而不是句尾语气词。

## 4. 同一场面的直给版

```text
姐姐：钥匙。
弟弟：没交。
姐姐：拿来。
弟弟：你先告诉我，母亲最后签的是哪一页。
姐姐：你不知道。
弟弟：所以我没交。
```

这句短、直、硬，但弟弟用问题夺回了控制权，姐姐也暴露自己并不知道答案。直给不等于没有策略。
