# 短剧台词专项

把已有场景意图变成可表演、会改变局面的交锋。台词专项处理用户点名的一段对白、一场对话或一组人物声音；
整集结构、场景增删和最终 `剧本.md` 仍由 `$short-drama-write` 负责。

## Quick Start

先锁定用户已经给出的事实、场景结果、人物知识、持物、动作、时间与指定原句。然后只读当前问题需要
的对白资料：

- 单句或几句台词：读[先定位问题](references/dialogue-direction.md#1-先定位问题)、
  [把台词写成行动](references/dialogue-direction.md#3-把台词写成行动)、
  [回应与反制](references/dialogue-direction.md#4-回应与反制)和
  [三遍重写](references/dialogue-direction.md#8-三遍重写)。
- 重排一场对话：读[压力链](references/dialogue-direction.md#2-压力链)、回应、潜台词、停顿与动作和
  三遍重写；需要对照完整改写时再读[合成示例](references/dialogue-examples.md)。
- 人物同声：读[人物声音](references/dialogue-direction.md#6-人物声音)与三遍重写。
- 所有权、规则分级或边界冲突：再读[阶段契约](references/stage-contract.md)。

普通单句修订不预加载整份参考与阶段契约，也不默认读取合成示例。

默认交付可直接替换的台词片段。用户问为什么时，再附最少的“策略变化”说明；不把内部检查表当正文交付。

```md
## 修订稿

角色甲（可执行提示）：……
角色乙：……
角色甲：……

## 改动依据

- 甲从……转为……，因为乙的动作改变了……
- 保留：……；未决：……
```

## 入口

- 只有几句台词：先判断是“写在鼻子上、所有人同声、说明过载、没有受阻，还是动作填充”，只修对应问题；
  若真正问题是场景本身没有变化，停止改台词并交 `$short-drama-write`。
- 有一场对白：读取这场开始与结束状态，重排说话者的策略、反制与代价，不新增剧情机关。
- 只有人物关系或声音样本：建立轻量声音差异，再写一次能验证差异的短交锋。
- 来自项目 `剧本.md`：返回可替换的局部台词块和保留项。需要写回文件时交 `$short-drama-write`。
- 同时要求改剧情结果、场景数量或整集结构：先由 `$short-drama-write` 确定新契约；本技能不替它决定。

## 工作流

1. **锁契约。** 记录这场必须改变什么、谁最终知道什么、哪些台词或事实不能动、可用动作与空间是什么。
   缺一条会改变结果的信息时才问一个具体问题；其余缺口按现有材料写作，并标为假设。
2. **排压力链。** 对每个承担冲突的说话者在上下文中确认：此刻要对方做什么、最怕暴露什么、知道什么、
   手里有什么筹码、先用什么策略、被什么挡住后会怎样换法。事务性角色保持简洁，不为检查表硬加秘密。
3. **先写行动，再写句子。** 用“试探／逼迫／交换／遮掩／划界／验证／拒绝／重新定义关系”等动词标出台词
   正在做什么。不能标出行动、也不承担必要信息的句子，改成动作、并入相邻台词或删去。
4. **让反制真实发生。** 听者可以回答、只回答安全部分、改写问题、用行动拒绝、拿证据反压或退出。
   重要一轮结束后，至少能指出信息、权力、关系、情绪位置或下一步动作的一项变化；没有变化就压缩。
5. **写潜台词。** 只有人物确实没有理由直说时才绕。给观众一个可观察依据：避开的词、改称呼、和可见事实
   矛盾的回答、被按住或交出的物件、第三人进入后改变的公开范围。没有隐瞒理由的普通指令保持普通。
6. **过人物声音。** 用人物注意什么、认定什么算证据、怎样控制距离、怎样自保、受压后怎样变形来区分声音，
   再用词汇与节奏微调。不要把口癖数量、方言词数量或每句长度当人物身份证。
7. **过表演。** 朗读一遍，检查一口气、打断、停顿、动作与台词是否互相重复。表演提示只写演员能执行的语气、
   对象或动作；不用括注代替戏剧行动。
8. **定点交付。** 保留未点名段落；给出替换稿、必要依据和真实未决项。用户没要求多个版本时不凑三版；
   要求比较方案时，让每版改变一个明确维度，不把同一种利落腔换皮。

## 写作要求

- 先服从用户已给出的事实、指定原句、人物知识边界和退出状态；不要为了让台词更刺激而补造债务、身份、
  证据、秘密、时间限制或旧关系。
- 台词首先执行动作。金句、狠话、幽默和诗意只有同时改变关系、权力或下一步选择时才留下。
- 说明只以人物当下有理由说、听众有理由听的方式进入：争夺解释权、问责、交换、验证、威胁、纠正或公开。
- 长说明先找可以打断、质疑、回避或交换的位置；内部没有策略转折时缩短，不靠均匀插入“皱眉、停顿、喝水”拆句。
- 沉默、打断和动作必须在现场有对象。听者不回应要能读出他在保护、等待、判断或拒绝什么，而不只是空拍。
- 短剧要求台词尽早进入压力，但不设固定秒数、句数、金句数或轮次数。节奏由这一场的策略变化与表演容量决定。
- 方言、粗口、重复、笨拙、含混、诗性和长句可以是人物风格；修订只解决有证据的问题，不把作者声音统一磨平。
- 本技能给的是修订稿，不是审查 verdict。需要独立审查时交 `$short-drama-review`。

## 按需知识

- 按 Quick Start 的问题路由只读[对白压力与重写](references/dialogue-direction.md)对应小节。
- 需要完整 Before/After 场景对照时，再读独立的[对白合成示例](references/dialogue-examples.md)。
- 只有需要判断局部修订与整集剧本的所有权、规则分级或交付边界时，才读[阶段契约](references/stage-contract.md)。

## 完成

用户点名的台词已能执行清晰行动，反制造成可追踪转向，人物声音与已知关系相符，潜台词有现场依据，
表演与现有动作容量相容，且没有越过剧情、资产、分镜或审查边界，即完成。
