## 1. 先定位问题

不要用同一套“加冲突”修所有台词。先找可观察的病征：

| 病征 | 常见原因 | 优先修法 |
|---|---|---|
| 太直、太假 | 人物没有隐瞒理由，或作者把结论直接塞进嘴里 | 补足当下风险；让人物只处理眼前能处理的部分 |
| 像会议记录 | 信息按主题排队，听众没有利益、疑问或反制 | 让信息成为筹码、指控、验证或公开的代价 |
| 每个人都一个味 | 差异只靠口癖，缺知识、证据观和关系策略 | 重做声音维度，再做换名测试 |
| 很平 | 一方要求、另一方完整回答，策略没有失败 | 让听者拒绝隐含条件，迫使说话者换策略或付代价 |
| 很吵但没戏 | 情绪词、狠话和动作多，局面仍不变 | 删装饰，找出这一场必须改变的结果 |
| 为潜台词而潜台词 | 没有不能说、怕失去或现场限制 | 该直说就直说；潜台词不是装饰 |
| 金句很亮，人物不像 | 句子服务作者，不服务人物此刻的风险 | 用人物会注意、会拿来证明的东西重写 |

先追问“这句话为什么现在由这个人对这个听众说”，再问“怎样说得更漂亮”。

## 2. 压力链

只给承担冲突的人建压力链。它留在上下文，不落成项目文档。

| 项目 | 角色甲 | 角色乙 |
|---|---|---|
| 此刻要让对方做什么 |  |  |
| 最怕失去什么 |  |  |
| 最怕对方知道什么 |  |  |
| 以为对方知道什么 |  |  |
| 可交换或可动用的筹码 |  |  |
| 第一策略 |  |  |
| 什么会使第一策略失败 |  |  |
| 失败后怎样换法或退出 |  |  |

四类信息差尤其有用：

- **知识差**：谁知道事实、谁知道对方知道、谁知道第三人在场。
- **证据差**：谁能证明、证据是否可公开、是否会被反证。
- **权限差**：谁能开门、结束谈话、调用资源、定义问题或决定后果。
- **代价差**：谁更怕失去关系、体面、安全、时间、身份或利益。

压力链不是要求每人每句都提交完整答案。它用来判断为什么这句会这样说，以及哪一句应该让对方无路可退。

## 3. 把台词写成行动

一句台词通常执行一个主要动作，也可以带一个掩饰动作。先选主要动作：

- 要求、命令、交换、拖延、拒绝；
- 试探、诱导、验证、套话、点破；
- 指责、倒转责任、缩小或扩大问题；
- 重定义关系、夺回称呼、划出边界；
- 展示或隐藏证据、把私人内容公开；
- 给出条件、撤回条件、暴露自己愿付的代价；
- 让对方在众人面前选择；
- 用沉默或离场迫使他方承担下一拍。

同一事实可以执行完全不同的动作。综合例：

```text
事实：门会在十点锁上。

催走：你还有十分钟。
推责：十点以后，钥匙不归我管。
试探：你这么怕锁门，是里面有人？
威胁：十点一到，里面是谁都不重要。
保护：十点前走，我就当没看见。
交换：你告诉我谁给的钥匙，我替你留门。
```

不要只把句子写得更有攻击性。攻击若没有改变对方的行动空间，仍只是噪音。

## 4. 回应与反制

一轮有张力的对白不只交换句子，也交换控制权。听者对上一句的处理通常落在以下位置之一：

- **正面回答**，但只回答对自己安全的部分；
- **拒绝回答**，用另一个问题、动作或公开事实暴露风险；
- **利用对方的词**，把同一个词变成反控；
- **改写问题**，争夺“真正要谈的是什么”；
- **验证对方**，要求证据、名字、时间或当场行动；
- **改变公开范围**，叫第三人进来、关门、拿起电话；
- **接受字面条件，拒绝隐含关系**；
- **退出**，并以离场让剩下的风险落到别人身上。

每次反制之后，原说话者至少应做出一个有依据的选择：换策略、加筹码、付代价、收手或越过底线。
若他只是把同一要求换个说法，压缩这一轮或让另一个人改变现场。

### 4.1 句尾承重

句尾通常是对方必须回应的词。把核心落点留在句尾，不一定写成金句：

- 落点弱：`我不是不愿意帮你，只是这件事有点麻烦。`
- 落点强：`我可以帮你。先告诉我，钥匙是谁给你的。`

落点在“钥匙是谁给的”，因为这一句真正要交换的是名字，不是帮忙。

押韵、诗性或习惯性的前置也可以成立。判断标准是听者接住了什么，而不是所有句子都同一种语序。

## 5. 潜台词与说明

### 5.1 潜台词先找不能说的原因

只有下列理由出现时，绕说才有戏：

- 说出来会失去关系、体面、安全或筹码；
- 现场有不该听见的第三人；
- 说话者还不确定对方知道多少；
- 直接请求会暴露自己更在乎；
- 说话者连自己都不愿承认。

观众需要可观察依据。可以避开一个具体词、改变称呼、把物件移开、先回答旁枝、和已知事实矛盾，
或在第三人来时突然改口。作者事后解释“他其实很痛苦”不算依据。

### 5.2 说明进入冲突

把“两人都对观众复述背景”改成至少一方有当下的利益：

- 争谁有权解释过去；
- 用过去换现在的行动；
- 为责任划界；
- 用证据迫使对方改口；
- 在公开场合改变一句话的代价；
- 故意省略一部分，让另一人补上。

人物彼此已经知道的信息只保留有争议的解释、当前的用途和关系后果。观众需要知道但人物不必说出的，
优先交给可见证据、前序行动或最小必要片段。

### 5.3 直接说也合法

以下场景不需要硬塞潜台词：

- 普通生活指令；
- 紧急协作或救人；
- 双方都已知道真相，争的是选择；
- 角色本来就直率，绕说反而不像他；
- 创作者明确要直给爽感、宣讲、审讯或仪式语言。

潜台词是策略选择，不是台词成熟的证明。

## 6. 人物声音

### 6.1 六个稳定维度

1. **注意什么**：流程、风险、体面、感受、物件、别人的反应或长期后果。
2. **认定什么算证据**：规则、亲眼所见、承诺、数字、关系、经验或权力。
3. **怎样控制距离**：直呼名字、称谓、简称、客气话、“我们”、避开代词。
4. **怎样自保**：解释、反问、开玩笑、沉默、攻击、过度精确或转移。
5. **受压怎样变形**：更简短、更正式、更礼貌、更粗暴、开始重复或突然坦白。
6. **对谁不一样**：面对上级、家人、爱人、陌生人或需要保护的人时使用什么不同策略。

口癖只是表层。真正的差异在于两人看到同一件事时先注意什么、拿什么证明自己、愿意冒什么险。

### 6.2 换名测试

交换说话者后：

- 如果剧情和关系几乎不变，说明台词只有功能，没有人物；
- 如果只是词汇不合但行动完全通用，说明口癖多、策略少；
- 如果交换后明显违背谁知道什么、谁怕什么、谁愿意付什么代价，声音基础较稳。

不要为了通过测试给每个人发一个固定词。人物可以在一场戏中偏离常态，因为关系或压力变了。

### 6.3 关系特异

同一个人不会对所有对象使用同一种说话方式。称谓、句长、礼貌程度、是否解释、是否能开玩笑，
都应随当前关系位置变化。称呼变化常常比一段自我说明更能表现关系转向。

## 7. 停顿、打断与动作

### 7.1 什么动作值得写

对白间的动作至少做一件事：

- 改变谁能看、听、拿、留下或离开；
- 操作筹码、证据或会改变下一句话的物件；
- 暴露台词与行为不一致；
- 给出对方必须回应的新事实；
- 留下下游需要延续的持物、站位或状态。

“看一眼、笑一下、皱眉、喝水”可以存在，但当它们被均匀塞在每句后面时，通常只是说话者标签。
不要用动作密度证明对白活跃。

### 7.2 停顿有对象

不要只写“沉默片刻”。让读者知道这段停顿在等什么、避什么或衡量什么：

```text
甲把钥匙从钥匙圈上拆下来。

甲：你先把门开了。

乙没有伸手。他把拆下来的钥匙扣进掌心，转头看向第三个人。

乙：你问她。门是谁锁的？
```

停顿改变了选择：甲原本想交换，乙把问题公开给第三人。

### 7.3 打断留下后果

打断可以阻止一个危险词被说出、抢走问题定义权、保护某人或暴露打断者已经知道答案。
被打断的信息若之后没有别的方式让观众得到，不能只靠打断制造节奏。

## 8. 三遍重写

### 第一遍：压力

1. 写下这场结束时必须改变的事实。
2. 给每个主要说话者标一个当前策略。
3. 找到策略第一次受阻的位置。
4. 让听者的回应改变下一句话、动作或选择。
5. 删掉没有改变任何东西的寒暄、确认和同义重复。

### 第二遍：声音

1. 遮住名字，能否分出谁在注意什么、拿什么证明自己？
2. 每人最怕被看见的事，是否影响了他选择说哪一部分？
3. 称呼与公开范围是否随关系变化？
4. 压力下是否仍像这个人，而不是突然变成作者？
5. 删除仅靠口头禅、网络词或方言拼出的差异。

### 第三遍：表演

1. 逐句朗读，能否在现有动作与呼吸中说出？
2. 句尾是否落在对方必须处理的词上？
3. 括注是否只给可执行的语气、对象或动作？
4. 动作是否和台词重复，或只是在填满停顿？
5. 重要话语后是否有可见后果，而不是说完就算？

### 8.1 需要给变体时

每版只改变一个明确维度，方便创作者选择：

- **压力版**：保持潜台词，加强筹码与代价；
- **直给版**：缩短绕说，适合宣战、公开打脸或紧急现场；
- **声音版**：保持事实与策略，替换注意对象、证据观与控制距离；
- **克制版**：减少话语和动作，让沉默、物件或公开范围承担变化。

不要默认输出四版。用户只要一版时，选最符合场景契约的一版。

## 9. 完成检查

用具体台词和相邻动作回答，不用空泛评分：

1. 每个主要人物此刻想让对方做什么？
2. 他的第一策略被什么挡住，之后怎样换法？
3. 哪一句或哪个动作改变了信息、权力、关系或下一步？
4. 潜台词为何必须存在，观众依据什么推断？
5. 必要信息为何必须由这个人在此刻对这个听众说出？
6. 交换说话者后，哪些台词会失去人物逻辑？
7. 动作、停顿与打断是否改变现场，而不只是装饰？
8. 删除解释性句子后，画面与下一动作是否仍能看懂？
9. 修订是否只解决已指出的问题，并保留作者原句中有意为之的粗糙与风格？
